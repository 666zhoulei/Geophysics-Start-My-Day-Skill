# Acknowledgements / 致谢

This distribution is adapted from the `evil-read-arxiv` skill collection. The original project supplied the general arXiv/Semantic Scholar search, paper-analysis, image-extraction, Obsidian-note, and knowledge-graph workflow. This fork specializes that workflow for geological resources and geological engineering, especially exploration geophysics and seismic data processing.

本发布包基于 `evil-read-arxiv` skills 集合改造。原项目提供了 arXiv/Semantic Scholar 检索、论文分析、图片提取、Obsidian 笔记与研究图谱等基础工作流。本分支重点增加了地质资源与地质工程方向的兴趣配置、本地 PDF 保留与链接、Windows 环境适配，以及地球物理相关性筛选。

Thanks also to:

- [arXiv](https://arxiv.org/) for open preprints and its public API.
- [Semantic Scholar](https://www.semanticscholar.org/) for scholarly metadata and citation signals.
- [Obsidian](https://obsidian.md/) for the local Markdown knowledge-base workflow.
- [OpenAI Codex](https://developers.openai.com/codex/) for the skill runtime and development environment.
- [PyMuPDF](https://pymupdf.readthedocs.io/) for PDF processing and figure extraction.
- Zotero and the user's local Zotero library for informing the geophysics interest profile.
